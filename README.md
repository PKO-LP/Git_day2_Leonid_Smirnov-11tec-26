# Что такое Git и как с ним работать?

**Git** — это распределенная система контроля версий, которая сохраняет историю изменений кода, позволяет откатывать проект назад и помогает программистам работать в команде без потери данных.

## Главные команды и понятия

Для управления проектом используются специальные команды в терминале:

```bash
git init
```
> **Инициализация:** создает новый локальный репозиторий и включает отслеживание Git в текущей папке.

```bash
git status
```
> **Проверка состояния:** показывает статус файлов (какие изменены, добавлены в индекс или еще не отслеживаются Git).

```bash
git add
```
> **Индексация:** подготавливает файлы, добавляя изменения в индекс (*staging area*) для следующего сохранения.

```bash
git commit
```
> **Фиксация:** сохраняет изменения в историю проекта (делает постоянный «снимок» состояния файлов).

---

## Зачем комментировать коммиты?

Комментарии к коммитам (сообщения) критически важны. Они нужны, чтобы **понимать суть изменений**. 

Без внятных комментариев вы и ваша команда не сможете:
* Быстро разобраться в истории проекта.
* Найти причину возникновения багов.
* Вспомнить спустя время, зачем был написан тот или иной кусок кода.
